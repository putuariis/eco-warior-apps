# Game Design

Core loop:

REAL ACTION → EVIDENCE → COMMUNITY VALIDATION → VERIFIED IMPACT → ECO-TOKENS/XP → LEADERBOARD → LIMITED REWARD

Verification defaults:
- VERIFIED when likes >= 5 and dislikes < 3 and reports < 3.
- INVALID when reports >= 3 or dislikes >= 3.
- PENDING otherwise.

For real deployment, verification should also consider account age, duplicate evidence, moderation, risk score, and human review. Never issue monetary-equivalent rewards solely from an unverified community vote.

Ranks:
Eco Rookie → Green Scout → Eco Warrior → Climate Guardian → Earth Champion → Planet Legend.
